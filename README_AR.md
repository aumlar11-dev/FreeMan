# Free Man | فري مان

مشروع Android أولي مفتوح المصدر لتخطيط القصص والأفلام باللهجة العربية/العراقية.

## الموجود في النسخة الحالية
- واجهة عربية داكنة باسم Free Man.
- إدخال فكرة الفيلم والنوع والمدة.
- إنشاء مخطط مشاهد نصي محلي (4 مشاهد للفيلم القصير و8 للطويل).
- مكتبة أدوار صوتية عراقية مقترحة (راوي، طيب، شرير، امرأة، طفل، مسن).
- مشاركة/تصدير مخطط المشاهد كنص.

## ما لم يُنفّذ بعد (بشفافية)
هذه ليست نسخة مكتملة لتوليد فيديو أو صوت. لا يوجد حالياً توليد صوت فعلي، أو اتصال بمزود AI، أو مونتاج/تصدير MP4. صفحات الأصوات والخدمات حالياً واجهات أولية. يلزم اختيار مزود فعلي واختبار شروطه وحدوده قبل ربطه. لا توجد مفاتيح API مضمنة.

## بناء APK عبر GitHub Actions من الهاتف
1. أنشئ مستودعاً جديداً في GitHub وارفع محتويات هذا المجلد.
2. افتح تبويب Actions وشغّل workflow `Build Android APK`.
3. نزّل artifact باسم `FreeMan-debug-apk` بعد نجاح البناء.
4. افتح APK على هاتفك واسمح بالتثبيت من المصدر الذي استخدمته.

يمكن أيضاً فتح المشروع في Android Studio ثم تنفيذ `gradle assembleDebug` بعد تثبيت Android SDK المناسب.

## متطلبات البناء
- JDK 17
- Android SDK Platform 36 وBuild Tools المناسبة
- Gradle 8.13

## الخصوصية
النسخة الحالية لا ترسل فكرة القصة إلى أي سيرفر. عند إضافة خدمات خارجية لاحقاً يجب توضيح البيانات المرسلة للمستخدم وعدم وضع مفاتيح سرية داخل التطبيق.
